# EmbedPix v0.7.13

## 发布内容

- 修复自定义标题栏关闭按钮可能被二次 `closeRequested` 事件拦截的问题：关闭前仍执行活动任务的有界清理，清理完成后使用 Tauri 直接销毁窗口。
- 在“保留原始元数据（原字节透传）”模式下，禁用不会生效的编码、缩放和目标体积参数，避免用户修改无效设置；输入限制、输出位置和覆盖策略保持可用。

## 验证

- 前端类型检查、lint、421 项测试、生产构建通过。
- Rust fmt 与 clippy（`-D warnings`）通过。
- Windows x64/ARM64 签名安装包、更新清单和发布资产由发布流水线复核。
