# EmbedPix v0.7.11

## 发布内容

- 修复自绘标题栏关闭按钮在任务清理和原生关闭事件竞态下可能无响应的问题。
- 按钮点击、系统关闭和 Alt+F4 统一等待活动任务清理，再安全关闭窗口；关闭失败时恢复交互状态。
- 新增同格式静态 PNG/JPEG/WebP 的“保留原始元数据（原字节透传）”策略，输出字节与输入一致，并明确拒绝跨格式、尺寸调整和目标体积压缩组合。
- 压缩预览、估算和正式结果会将该路径标识为“原字节透传”。

## 验证

- 前端测试、Rust 测试、clippy、发布配置与本地 release fixture 均通过。
- Windows x64/ARM64 安装包、签名资产、更新清单和跨平台门禁由发布流水线复核。
