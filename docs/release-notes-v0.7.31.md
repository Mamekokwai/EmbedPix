# EmbedPix v0.7.31

## 变更

- 自定义下拉改为视口浮层：不再被设置卡片裁剪，短窗口自动向上展开，超出部分在浮层内滚动。
- 工作区与预设导入、主题选择、已导入文件列表改用标准控件语义（真实按钮 / 真实单选 / 列表项），键盘与读屏可用；导出过程中整组输出设置禁用。
- 主视图滚动条由完全隐藏改为 6px 细滚动条，长页面可发现；列表内部滚动条同步收细。
- 修复 6 个被样式引用但从未定义的设计 token，以及失效的 `--qp-accent`、`--qp-border` 引用，恢复主题色、圆角与动效的一致表现。
- 画布尺寸与边距标签在窄窗口不再换行或被输入框挤压；补齐 760 / 620 / 560 / 500 断点。

## 兼容性

- 不改变图片转换、压缩、GIF 编码、更新协议或文件输出格式。
- 继续支持 Windows x64 与 ARM64 发布资产。

## 验证

- 前端 `check:types`、`check:lint`、Vitest（34 文件 / 434 项）与 `npm run build` 通过。
- Rust `cargo fmt --check`、`clippy --all-targets --locked -- -D warnings`、`check --locked`、`test --locked`（287 项）通过。
- 五个界面在 1100×760 / 700×1100 / 620×700 / 500×680 / 480×560 / 360×500 六档视口下无横向溢出，下拉浮层均完整落在视口内。
