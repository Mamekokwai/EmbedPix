# EmbedPix v0.7.31

## 变更

- 自定义下拉改为视口浮层：不再被设置卡片裁剪，短窗口自动向上展开，超出部分在浮层内滚动。
- 压缩参数改为分组收纳：预设管理 / 编码细节 / 目标体积 / 输入与跳过 / 输出与元数据，默认只留预设、格式、质量与缩放；每组标题显示当前状态，危险项与无效参数在标题上标红。
- 参数出错时显示始终可见的「参数问题」提示，避免字段被折叠后看不出“开始压缩”为什么不可用。
- 压缩页套用与转换页一致的页面外壳：品牌头带（图标 + EMBEDPIX / 图片压缩工作台 + 本地处理）、介绍带（IMAGE COMPRESSION + 标语 + 说明），底部动作栏加顶边线并以品牌行收尾。
- 用不上的参数直接隐藏而不是留成灰控件：压缩页在 PNG 或无损 WebP 下不再显示质量、输出尺寸缩放与目标体积，JPEG 下只留 JPEG 专属项，WebP 无损下只留无损项；转换页在 JPG / RGB565 下不再显示位深选择框。导出进行中等「暂时不可用」的控件仍保留原有禁用形态。
- 压缩页所有下拉改用与格式转换页同一个主题化下拉控件：外观、浮层、键盘操作与选中态一致，不再是系统原生 select。
- 修复「导出成功后删除源图片」等开关被点击后整个界面（含标题栏）被顶出窗口、无法操作的问题：开关类复选框是绝对定位且没有定位祖先，会以初始包含块为基准逃出主滚动层的裁剪、把文档撑高，浏览器把焦点元素滚进视野时滚的是文档而不是主滚动层。现在文档彻底不可滚动（`html` 用 `overflow: clip`，`hidden` 仍可被编程滚动），主滚动层兼作定位祖先（`.app-main` 设 `position: relative`）。
- 转换页带说明文字的设置组改为通栏，并去掉按开关宽度（38px）的左缩进：说明被挤进半栏或缩进到勾选框文字下方时，宽度与起点跟同页其它说明都对不齐，看起来像属于那个勾选框。
- 转换页的开关说明默认收起，鼠标停在开关上（或键盘聚焦）约 0.4 秒后浮出，移开立即收起：折叠面板不再被逐条解释占满。说明只是视觉收起，仍留在 DOM 中，`aria-describedby` 与读屏不受影响。键盘路径用 `:focus-visible` 判定，鼠标点过开关后移开鼠标不会把浮出框留在屏幕上。
- 竖向组件间距统一：设置面板里堆叠的控件行、设置组与勾选组共用同一个间距 token（`--qp-stack-gap`，7px），短窗媒体查询也用它；相邻的四个开关不再出现 5px / 7px / 8px 三种间距。
- 子文件夹支持相对路径：`out/A` 与 `out/A/` 都写到 源文件夹/out/A/（分隔符与首尾斜杠等价，逐段校验，拒绝 `.`/`..`、绝对路径与系统保留名）；目录缺失时递归创建。选项与字段统一叫「子文件夹」，自动创建那句写进输入框占位符。
- 输出位置去掉「覆盖原图」（源文件夹 + 覆盖同名文件即可达到同样效果）和「导出后自动使用对应目录」注释；源文件夹模式下的「直接保存到源图片所在文件夹。」也删掉，输出位置不再挂常显说明。「重复目标自动编号」开关下线，重复目标改为在「示例目标」行直接报出。输出目录的自动创建说明同样移进占位符。
- 「覆盖同名输出文件」改名「覆盖同名文件」；新增「重命名」开关，默认关闭时按导入图片的文件名输出，打开后才出现文件名模板与变量说明（说明悬停显示，浮层紧贴输入框）。
- 文件名模板的变量说明改为逐条解释：`{name}` 源图片名、`{ext}` 输出扩展名（含 RGB565 → bin、C 数组 → h）、`{width}`/`{height}` 源图像素尺寸、`{index}` 批次序号，并写明不支持其它占位符、不能写路径分隔符、缺扩展名会自动补上。
- 重命名健壮性：生成文件名与子文件夹按 Windows 规则逐项校验并当场报错（`<>:"|?*`、结尾点或空格、超长 255、CON/AUX 等保留名、`.`/`..` 穿越），扩展名一律强制成输出格式（与原生侧一致，示例目标不再和真实文件名错位）；修掉规划层仍按「禁止分隔符」拒绝子文件夹导致 `out/A` 整条链路失败的问题；规划失败的原因直接显示在面板上，不再要等到点导出才知道。
- 「背景色」改名「透明色」并去掉「透明区域使用此颜色」注释，位深与格式说明同步改用新名字；设置页的「默认背景色」一并改名。
- 「子文件夹不存在时会自动创建。」移入子文件夹名称输入框的占位符，删掉下方重复的一行注释；该说明改为按需渲染，`aria-describedby` 不再指向不存在的元素。
- 工作区与预设导入、主题选择、已导入文件列表改用标准控件语义（真实按钮 / 真实单选 / 列表项），键盘与读屏可用；导出过程中整组输出设置禁用。
- 主视图滚动条由完全隐藏改为 6px 细滚动条，长页面可发现；列表内部滚动条同步收细。
- 导入类按钮的图标由向上箭头改为向下箭头，导出按钮同步改为向上箭头：导入与导出不再共用同一个方向的箭头，一眼能分清进和出。
- BMP 32 位新增「填充透明色」：勾选后透明区域按上面的透明色合成，输出不再保留透明度；预览与导出走同一套逻辑，CLI 导出元数据新增可选字段 `fillTransparent`。
- 页面介绍标题简化：「转换图片，适配你的嵌入式界面」→「转换图片」，「压到目标体积，格式与画质可控」→「图片压缩」。
- 去掉互相重复的界面说明：位深标签行不再复述候选位深，「支持 1、4、8、16、24、32 位；仅 32 位保留透明度。」整句不再渲染（位深控件就在下面），拖入区不再显示「或点击选择一个或多个本地文件」，转换页空状态不再显示「导入图片后开始设置输出参数」，压缩页与 GIF 页的同类「或点击选择…」提示一并删掉。
- 修复 6 个被样式引用但从未定义的设计 token，以及失效的 `--qp-accent`、`--qp-border` 引用，恢复主题色、圆角与动效的一致表现。
- 画布尺寸与边距标签在窄窗口不再换行或被输入框挤压；补齐 760 / 620 / 560 / 500 断点。

## 兼容性

- 不改变图片转换、压缩、GIF 编码、更新协议或文件输出格式。
- 继续支持 Windows x64 与 ARM64 发布资产。
