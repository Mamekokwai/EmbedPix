# EmbedPix v0.8.0

## 变更

- 主题系统整套对齐 patina：逐行移植它的主题推导（`surface` / `ink` / `accent` 派生全部颜色 token），浅色 16 套 / 深色 27 套配色预设，明暗各选一套，跟随系统时按当前明暗分别生效；主色按钮底色按 patina 的算法压暗到 4.5:1（文字恒为白），转换页导出键、压缩页「开始压缩」与赞助弹窗的 Ko-fi 键都改用新的主色 token。
- 设置页配色方案改为 patina 式的色卡选择：一行显示当前方案 + 「更改」按钮 + 色卡网格弹窗，六格色样与 patina 同序，不再用下拉框。
- 设置页引入草稿态：页面里的改动先进入草稿，点「保存」才一次性落盘，「取消」丢弃；顶栏改为 sticky 悬浮（不透明底 + 1px 分隔线），右侧放状态提示与保存/取消，文案对齐 patina（有未保存更改 / 正在保存… / 配置已更新）。
- 主题草稿实时预览：在设置页改主题模式、浅色主题或深色主题会立即应用到界面（走同一套 `resolveTheme` 推导），取消回退、离开页面丢弃、保存才写入本机偏好；预览状态不写进 `localStorage`。
- 切页保护：设置页有未保存改动时切换到别的页面会弹确认框（保存更改 / 当前页面有未保存更改，保存后再切换页面。），确认才保存、保存成功才跳转，取消留在原页且不动草稿，Esc 等同取消。
- 五页页头与卡片标准化（以图片转换页为基准）：卡片间距统一 16px、两栏工作区网格统一 18px、固定页头统一 `min-height 34px + padding-bottom 10px + 1px` 底边线（合计 45px）、页面外层内边距统一 `20px 28px 18px`、页头到内容留 14px；图片转换 / 图片压缩 / GIF / 设置 / 关于五个页面一视同仁，规则与基准值写进 AGENTS.md 并由契约测试锁定。
- 五个页面的页头统一为两行锁定（带框图标 + `EMBEDPIX` + 工作区名）与同一图标框、同一字号体系；压缩页与 GIF 页的介绍带（英文 eyebrow + 标语 + 说明）与「● 本地处理」状态点一并删除。
- 挤占式布局与滚动下沉：滚动从外层壳层移到各页内容区，`.app-main` 不再滚动，页头固定、内容区自带纵向滚动，卡片撑满可用高度、列表在卡片里滚（对齐 patina）；图片转换、图片压缩、GIF、设置、关于五页完成迁移。
- 图片转换 / 图片压缩 / GIF 三页根元素改为撑满高度的弹性列，头部固定、主体各自形成滚动区；GIF 页不再由根滚动，展开设置改为撑开工作区；输出格式卡片按剩余高度自适应，折叠卡片延迟滚动以避免撑破相邻卡片，导入图片列表在短窗口下仍可触达。
- 全局隐藏可拖动的滚动条，页面与卡片仍保留滚轮、触控板、键盘与程序滚动。
- 窗口最小尺寸对齐 patina 的 900 × 636（原 480 宽 / y 轴 560）：无边框窗口改由 Rust 侧创建并在创建期传入 `min_inner_size`，`tauri.conf.json` 的 `app.windows` 置空；实测系统不采纳无边框窗口的 `set_min_size` / `WM_GETMINMAXINFO`，改为在 `Resized` 事件里按物理尺寸顶回，强缩到 500×400 会被顶回不小于 900×636。窄于 900 的 `max-width` 断点整批删除（26 删 + 8 块只保留 `max-height`），契约测试加了禁令并更新视口矩阵。
- 桌面应用不再显示 WebView 默认右键菜单：拦截 `contextmenu`，但在 `input` / `textarea` / `contenteditable` 内保留，避免连复制粘贴一起失效。
- 裁剪实时预览：预览框按裁切区域定形（窗口比例 = 裁切宽高比），源图放大到裁切框宽度后按裁切原点反向平移、只露出裁切范围；旋转与翻转叠加在裁切窗口之外，顺序与原生 `apply_image_transform`（裁切 → 旋转 → 水平/垂直翻转）一致，源图预览与「输出预览」两处同时生效；并新增实时变换预览开关。
- 关于页按 patina 重排：居中留白、图标壳、作者卡片与按钮限宽；11 个格式标签按类别收成三块（细节留悬停提示）；GitHub Star / 更新说明 / 问题反馈 / 赞助项目按钮移进简介卡，赞助弹窗按 patina 结构重做（微信赞赏 + Ko-fi 两张卡，标题图标用各自的官方 mark，赞赏码整张放大不裁切）。
- 侧栏导航图标缩到 patina 的尺寸，标题栏改为悬浮在工作区之上。
- 输出设置收敛：转换页左栏改为弹性列并自带内滚，修复左栏三个按钮被后绘制的页脚盖住、点不到的问题；位深、输出尺寸与带说明的设置组统一通栏。
- 安全目录导入放宽，允许受信任来源的目录导入；32 位 BMP 新增「填充透明色」（勾选后按透明色合成、输出不再保留透明度，预览与导出同一套逻辑，CLI 导出元数据新增可选字段 `fillTransparent`）。
- 主题相关 effect 收窄到真正影响主题的字段，去掉未使用的对比度覆盖链，避免每次改动都重跑推导。

## 兼容性

- 不改变图片转换、压缩、GIF 编码、更新协议或文件输出格式。
- 继续支持 Windows x64 与 ARM64 发布资产。
