# EmbedPix v0.7.2

## 变更

- 压缩工作台新增原图与压缩结果的滑动对比预览，保留并排预览，并支持键盘操作。
- JPEG 与 WebP 有损目标体积压缩支持 `maxRgbMae` 视觉质量门槛；JPEG 透明输入按设定背景色比较。
- CLI 的目标体积、自动缩放和 RGB MAE 参数统一支持大小写不敏感的 JPEG/WebP 格式名称。
- 修复预览结果被替换或清空后残留滑动对比状态的问题。
- 修复发布工作流完整 Rust 格式门禁发现的更新模块 import 排序问题。

## 验证

- 前端测试、生产构建、Rust 核心测试、压缩 CLI smoke、桌面 smoke 和本地 release fixture 在发布前执行。
- Windows x64/ARM64 安装包由发布工作流重新构建并签名；发布后仍需执行真实资产下载、签名、安装和启动 smoke。

## 兼容性与限制

- 不改变 updater 公钥、更新协议或已有输出覆盖策略。
- ARM64 原生安装启动、真实 GitHub Release 资产与签名结果必须以新 tag 的发布工作流验收为准。
