# EmbedPix v0.5.0

## 主要更新

- 修复图片格式持久化与导出后状态保存问题。
- 支持导出后打开目标目录、复制输出路径和剪贴板导入。
- 增加嵌入式输出检查器与用户预设。
- 增加批量命名模板和自动序号，以及文件夹递归导入。
- 增加 GIF 预设与对应质量/体积回归门禁。
- 更新安装流程增加首次启动健康诊断；未完成启动验证时会在更新状态中提示。
- 修复 GIF spool 并发清理和生命周期竞态。
- 发布 smoke gate 使用真实公钥对 x64/ARM64 安装包执行 minisign 验签，并校验 manifest、provenance 和 SHA256SUMS。

## 兼容性与限制

- 发布目标仍为 Windows x64 和 ARM64。
- WebP 有损质量能力仍受当前编码后端限制，不宣称与 `cwebp` 等工具的质量参数完全等价。
- ICC/EXIF 原样保留仍不支持；`metadataPolicy=preserve` 仅允许满足安全能力契约的受限直通。
- 安装失败后的自动回滚仍未支持；当前提供安装前校验、首次启动健康诊断和失败日志路径。
