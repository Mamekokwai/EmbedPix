# EmbedPix v0.7.6

## 稳定性改进

- 压缩参数在空闲状态变化后会清理上一批任务的旧结果、体积统计、最近输出路径与预检预算，避免显示与当前参数不符的信息。
- GIF 视频 FPS、抽帧间隔、最大帧数、裁剪、旋转和倒放参数变化后，会清理旧的规划、摘要和输出路径，同时保留已提取帧供重新抽帧。
- GIF 与压缩相关的图片尺寸读取、预览加载、视频元数据和导入任务支持超时、取消及资源清理，减少窗口切换或取消后的迟到回写。
- 更新页面只在真正完成版本检查时刷新“上次检查”时间；下载取消、下载完成和安装失败不会伪装成新的检查。
- 发布后 `latest.json` 校验请求加入无缓存头，降低 CDN/代理缓存旧 manifest 导致发布误失败的概率。

## 验证

- 前端 34 个测试文件 / 421 项测试通过。
- GIF Rust 35 项测试、图片导出与回滚 Rust 46 项测试通过。
- 生产构建、Windows GUI 子系统契约与桌面 smoke 通过。
